# Симплекс-метод (Проект «simpleks»)
## Теория принятия решений (БГТУ «Военмех», авторы: Е.Е. Воробьёва, В.Ю. Емельянов)

Интерактивная программа с **веб-интерфейсом** и **CLI-режимом** на Node.js для решения **произвольных задач** линейного и целочисленного программирования симплекс-методом с детальным расписыванием хода решения по пунктам и действиям.

Строго соответствует методическому пособию **`TPR.pdf`**:
- **Раздел 3.2 (стр. 24–30)**: Симплекс-метод (алгебраический и табличный варианты).
- **Раздел 3.3 (стр. 30–35)**: Решение целочисленных задач методом Гомори (первый алгоритм Гомори).
- **Раздел 3.5.7 (стр. 68–71)**: Проверка нелинейных ограничений и метод отсечений Данцига.

## 🌟 Возможности веб-интерфейса

1. **Решение любого уравнения / задачи ЛП**:
   - Динамическое добавление/удаление переменных ($x_1, x_2, x_3, \dots$);
   - Динамическое добавление/удаление любых ограничений с любыми знаками ($\le, \ge, =$);
   - Выбор направления оптимизации: **max** или **min**;
   - Опция целочисленности (метод Гомори);
   - **Универсальная проверка нелинейных условий**:
     - Поддерживает произвольные выражения: $x_2 \lg(x_1) > 1$, $x_1 \cdot x_2 \le 25$, $0.5 \le x_2/x_1 \le 2$, $x_1^2 + x_2^2 \le 100$;
     - Поддерживает функции `lg` (десятичный логарифм $\log_{10}$), `ln`, `log`, `sqrt`, `abs`, степени `^`;
     - Неявное умножение ($2x_1$, $x_2 \lg x_1$, $x_1 x_2$) и ввод переменной как латиницей, так и русской буквой «х»;
     - Отображение исходного условия, подстановки числовых значений и точного сравнения;
     - **Отсечения Данцига** (раздел 3.5.7, стр. 69–70): если найденное целочисленное решение не удовлетворяет нелинейному условию, алгоритм автоматически формирует правильное отсечение Данцига ($\sum x''_j \ge 1 \implies x_{new} = -1 + \sum x''_j \ge 0$, строка $[-1, -1, \dots, -1]$) и продолжает двойственный симплекс-метод до нахождения подходящего решения.
2. **Быстрые кнопки загрузки (пресеты)**:
   - **Свой пример** (задание придуманное из головы и проверенное);
   - **Пример 14** из методички (стр. 22–30);
   - **Пример 15** (метод Гомори, стр. 31–34);
   - **Очистить форму** — для ввода своей собственной задачи.
3. **Расписывание хода решения по пунктам и действиям**:
   - **Пункт 1. Постановка задачи и приведение к ОЗЛП** (базисные переменные, форма разложения).
   - **Каждый этап (Таблица 1, Таблица 2, ...) разбит на действия**:
     - *Действие 1. Базисное решение и разложение* (формулы $q$ и $x_i$ через свободные переменные);
     - *Действие 2. Анализ допустимости и оптимальности* (проверка столбца 1 и строки $q$);
     - *Действие 3. Выбор ведущего столбца и ведущей строки* (с **таблицей вычисленных отношений $\alpha_{ij*} / \alpha_{i0}$** и выбором максимума по Правилу 3);
     - *Действие 4. Вычисление промежуточных («новых») коэффициентов $\alpha^*$* (Правила 1–4, стр. 28–29);
     - *Действие 5. Симплекс-таблица (Линейный план)* с визуальной подсветкой генерального элемента $\lambda$ и ведущих строки/столбца. В каждой ячейке: сверху старый коэффициент, снизу промежуточный $\alpha^*$;
     - *Действие 6. Переход к следующему плану* (Правила 5–7, перестановка переменных и сложение $\alpha + \alpha^*$).
   - **Блок метода Гомори** (при наличии нецелых переменных): расчёт дробных частей $\{\alpha\}$ и добавление правильного отсечения.
   - **Итоговый результат**: вектор решения, максимальное значение $q$, проверка ограничений.

## 🚀 Запуск программы

### Вариант 1. Веб-интерфейс в браузере (Рекомендуемый)

Перейдите в папку `simpleks` и запустите локальный сервер:
```bash
cd simpleks
npm start
```
Сервер запустится по адресу: **`http://localhost:3000`** и автоматически откроет страницу в браузере.

*(Вы также можете просто открыть файл `index.html` в любом браузере двойным кликом — сервер не обязателен, все вычисления работают автономно!)*

### Вариант 2. Консольный запуск (CLI)

- Решение **Свой пример**:
  ```bash
  node simplex.js
  ```
- Решение **Примера 14** из методички:
  ```bash
  node simplex.js --example14
  ```

## 📁 Структура проекта `simpleks`

- `index.html` — разметка интерактивного веб-интерфейса;
- `style.css` — стили, подсветка таблиц и адаптивный дизайн;
- `app.js` — управление конструктором задач и отображение действий;
- `simplex-core.js` — математическое ядро алгоритма (класс Fraction, канонизация, Симплекс и Гомори);
- `simplex.js` — консольная версия для запуска в терминале;
- `server.js` — встроенный веб-сервер Node.js (без сторонних npm-зависимостей).
